Acerca de la Pokédex

Una aplicación web moderna desarrollada con Spring Boot para explorar la primera generación de Pokémon

¿Qué es esta aplicación?

Esta es una Pokédex digital que contiene información detallada sobre los 151 Pokémon de la primera generación. Desarrollada como un proyecto de demostración de las capacidades de Spring Boot, incluye una interfaz web moderna y una API REST completa.

Características Principales

Búsqueda Avanzada

Busca Pokémon por nombre, número o tipo. Encuentra rápidamente la información que necesitas.

Estadísticas Detalladas

Visualiza todas las estadísticas base de cada Pokémon con gráficos interactivos y fáciles de entender.

Diseño Responsivo

Interfaz optimizada para todos los dispositivos, desde móviles hasta computadoras de escritorio.

API REST

La aplicación también incluye una API REST completa para desarrolladores:

  • GET /api/pokemon - Obtener todos los Pokémon
  • GET /api/pokemon/{numero} - Obtener Pokémon por número
  • GET /api/pokemon/nombre/{nombre} - Obtener Pokémon por nombre
  • GET /api/pokemon/tipo/{tipo} - Obtener Pokémon por tipo
  • POST /api/pokemon - Crear nuevo Pokémon
  • PUT /api/pokemon/{id} - Actualizar Pokémon
  • DELETE /api/pokemon/{id} - Eliminar Pokémon
